# Roomy Bundles

Bundles can hold several **unstackable items** (tools, weapons, potions, beds...) instead of just one.

- Fabric · Minecraft 26.3 · No dependencies (not even Fabric API)
- Configurable: `config/roomy_bundles.properties` → `unstackables_per_bundle` (1–64, default 8)

## Building
```
./gradlew build
```
The jar ends up in `build/libs/`.
